# Alexis Laundry Services — Website

The official website for **Alexis Laundry Services**, a pickup & delivery laundry, dry cleaning and pressing business based in Iworoko Ekiti, Ekiti State, Nigeria.

🔗 **Live site:** https://alexislaundryservices.netlify.app/

## What's on the site

- Overview of the business and its promise (About)
- Full price list for dry cleaning vs. pressing, by item
- A pickup request form that sends the details straight to WhatsApp
- Contact details, opening hours, and location
- Light and dark mode, and a mobile-friendly layout

## Tech

A single self-contained `index.html` file — no build step, no server, no dependencies beyond Google Fonts. Booking and contact both work through `wa.me` (WhatsApp Click-to-Chat) and `tel:` links, so the site needs no backend.

## Hosting

This site is hosted for free on **Netlify** at the link above, and mirrored here via **GitHub Pages**.
